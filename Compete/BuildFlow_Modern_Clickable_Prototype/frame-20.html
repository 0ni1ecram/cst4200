Data sources (tables → this frame)

facility_telemetry · 5 cols · 1 FKasset · 10 cols · 3 FKspatial_zone_room · 9 cols · 1 FKproject · 9 cols · 0 FK

Primary actions

  • pivot by asset/room
  • set alert thresholds
  • export window for audit
  • reconcile gaps to outage log feed

Validation & business rules

  • No metric row may exist without a live asset_id; orphan telemetry quarantines on ingest.
  • Gap → outage inference is an external log in this build — labelled derived, never written back as truth.
  • CO₂ intensity is a value feed joined on timestamp; carbon credits stay ledger-side (frame 22).

Roles / states

  • Facilities ops write thresholds only; data plant owns ingest; Owner dashboard read-only
  • stale feed (>15 min) · no assets commissioned yet · gap quarantine review
