Frame specification (from the wireframe pack)

Primary actions

  • import / re-sync IFC
  • run clash set
  • approve revision (blocks P34 award until done)
  • link element to wbs

Validation & business rules

  • Awarding a bid_package that contains an element in an unapproved revision is blocked.
  • structural_element and mep_system share the PK of bim_element via element_id — the subtype adds no second project_id; scope resolves through the parent.
  • 78 elements without wbs_id cannot be costed in frame 08.

Roles / states

  • Architect + BIM manager write; GC read
  • sync in progress · import failed (schema version) · element deleted upstream
