Primary actions

  • bind indicator to target
  • enter measurement
  • attach evidence record
  • run compliance roll-up
  • export SDG report

Validation & business rules

  • Actual outside [0.5×, 10×] baseline rejects until re-confirmed — unit errors are common.
  • Evidence rows whose source record is deleted mark the target compliance_status as stale, not failed.
  • baseline_benchmark is external (UN data) joined by indicator_code; never free-typed.

Roles / states

  • ESG lead owns targets; data owners attach evidence; verifier read-only
  • first run (no targets) · evidence broken link · annual review lock
